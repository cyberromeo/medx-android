# Fonts

- **Plus Jakarta Sans** (Tokotype), SIL Open Font License 1.1 — headings, labels and numbers.
  Static weights 400/500/600/700/800 instanced from the variable font in google/fonts
  (`ofl/plusjakartasans`). https://github.com/tokotype/PlusJakartaSans
- Body and question text use the platform sans-serif (Roboto on most devices) for full Greek/µ
  coverage and long-form legibility.
